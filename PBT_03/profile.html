Về tôi

Đây là trang profile dùng để thực hành CSS Core. Nội dung tập trung vào cách sử dụng selector, box model, cascade và inheritance trong CSS.

Mục tiêu của bài là biết cách tách CSS ra file external, định dạng typography, navigation, table và footer một cách rõ ràng.
