# Infinite Scroll Gallery

**API:** Lorem Picsum — `https://picsum.photos/v2/list?page={n}&limit=20`

**Cách chạy:** Mở `index.html` bằng Live Server. Cần Internet.

**Tính năng:** infinite scroll (IntersectionObserver trên #trigger), lazy-load ảnh (IntersectionObserver thứ 2), lightbox khi click, grid responsive 4/2/1 cột.
