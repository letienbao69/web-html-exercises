# PBT_04 - CSS Layout

Thư mục này chứa bài làm Phiếu bài tập 04 về CSS Layout: Positioning, Flexbox và Grid.

## Danh sách file

| File/Folder | Nội dung |
|---|---|
| `answers.md` | Trả lời phần A, phần C và kịch bản video |
| `positioning.html` | Bài B1 - Positioning Playground |
| `positioning.css` | CSS cho bài Positioning Playground |
| `flexbox_layout.html` | Bài B2 - Flexbox Navigation & Cards |
| `flexbox.css` | CSS cho bài Flexbox Navigation & Cards |
| `grid_layout.html` | Bài B3 - Grid Layout E-Commerce |
| `grid.css` | CSS cho bài Grid Layout |
| `debug_flexbox.html` | File kiểm chứng phần C2 Debug Flexbox |
| `debug_flexbox.css` | CSS kiểm chứng trước/sau debug Flexbox |
| `screenshots/` | Ảnh chụp kết quả bài làm |
| `videos/` | Video OBS nếu nộp trực tiếp file video |

## Cách xem bài

Mở các file `.html` bằng trình duyệt hoặc dùng Live Server trong Visual Studio Code.
